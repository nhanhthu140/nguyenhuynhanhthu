Xin chào! Mình là Anh Thư 👋

Chào mừng bạn đến với kho lưu trữ mã nguồn trang web Portfolio cá nhân của mình. Trang web này được xây dựng bằng HTML5, CSS3 và thiết kế chuẩn Responsive nhằm giới thiệu về bản thân, các kỹ năng và những dự án mình đã thực hiện trong lĩnh vực Thương mại điện tử.

## 🎓 Về bản thân

- **Ngành học:** Sinh viên ngành Thương mại điện tử
- **Trường:** Đại học Kinh tế TP.HCM (UEH) - GPA: 3.48
- **Chứng chỉ:** TOEIC 850, Tiếng Nhật N4, Tin học văn phòng MOS.

## 🎯 Mục tiêu nghề nghiệp

Mình đang tìm kiếm cơ hội làm việc ở vị trí **Nhân viên vận hành sàn Thương mại điện tử (Shopee / TikTok Shop)**. Mình mong muốn được tham gia trực tiếp vào việc vận hành gian hàng, lập kế hoạch và triển khai các chương trình khuyến mãi (campaign) trên sàn, cũng như thực hiện báo cáo và tổng hợp, phân tích dữ liệu để tối ưu hóa doanh thu.

## 🛠 Kỹ năng chuyên môn

- Vận hành và quản lý gian hàng TMĐT (Shopee, TikTok Shop).
- Quản trị dự án.
- Hoạch định chiến lược Digital Marketing.
- Phân tích và báo cáo dữ liệu.
- Xây dựng và quản trị website (WordPress, WooCommerce).

## 🚀 Dự án tiêu biểu

1. **Gu Trà:** 
   - **Vai trò:** Quản trị dự án & Hoạch định chiến lược Digital Marketing.
2. **Ốc Len Shop:** 
   - **Mô tả:** Website thương mại điện tử chuyên kinh doanh các sản phẩm đan móc len và len sợi, được phát triển và tùy biến trên nền tảng WooCommerce.
3. **Len Rối:** 
   - **Mô tả:** Cửa hàng thương mại điện tử chuyên sản phẩm len hoạt động trực tiếp trên nền tảng Shopee.

## ⚙️ Cài đặt cục bộ (Dành cho nhà phát triển)

Nếu bạn muốn tải mã nguồn này về máy tính để xem hoặc chỉnh sửa:
1. Clone kho lưu trữ này về máy: `git clone https://github.com/[ten-tai-khoan]/[ten-repository].git`
2. Mở thư mục dự án bằng Visual Studio Code (hoặc bất kỳ trình soạn thảo mã nào).
3. Mở file `index.html` trực tiếp bằng trình duyệt (Chrome, Edge, Safari...) hoặc sử dụng extension "Live Server" trên VS Code để xem trực tiếp.
